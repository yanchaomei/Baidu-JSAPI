# 首个可运行版本设计

日期：2026-10-12。依据已确认的工业园区故事线与「继续，做到极致」授权执行。

## 范围与取舍

选择原生 TypeScript、Vite、Fetch Stream、Web Worker 和 WebGL，减少框架运行开销。首版使用固定种子的合成园区数据，覆盖点、线段和三角化区域。全部模式使用相同数据与绘制内核。

对比过的路线：全量 JSON 易实现但首批等待长；逐条 NDJSON 通用但对象与字符串解析开销较大；分块二进制更适合直接形成 GPU 数据。首版选择有版本号和长度校验的二进制帧，保留全量与主线程分块基线。

## 模块接口与不变量

- 数据协议：每帧包含几何类型、序号、要素数、顶点数和交错 Float32 数据。坐标为合成园区局部平面坐标，不能冒充经纬度。检查帧长度、类型、截断、有限数和计数一致性。
- 数据服务：同种子、同规模产生相同字节；响应支持背压；客户端断开后停止生成；生产服务与开发服务使用同一数据生成器。
- 流式会话：`start / pause / resume / cancel`；每个运行有独立编号；过期消息不再提交。Worker 仅在获得提交额度后继续发批，主线程消费后归还额度。
- 渲染器：`append / render / clear / dispose / stats`；按固定容量分配 GPU 页，增量写入；三类几何分别批量绘制；重复加载释放旧 Buffer。
- 视图：离线园区与真实地图适配共用 GPU 内核。真实百度图层必须以已核实合同与运行证据为门槛，不能自动以别的类冒充。
- 观测：记录网络、解析、提交、绘制阶段；帧时间 p95/p99、长任务、上传量和队列峰值。CPU/GPU 使用率无法测量时显示不可用。

## 用户体验

工业态势控制台展示园区主视图、几何图例、实时指标、数据规模与处理模式。提供开始、暂停、继续、取消、清空、持续状态更新和报告导出。页面明确标注合成数据及离线/百度地图状态。

未配置 AK 时允许独立渲染验证；用户可在本机配置入口填写 AK。凭据只留在用户选择的本地配置或会话中，不写入导出报告、URL、日志和仓库。

## 测试接口

1. 二进制解码公开接口：任意网络分片、坏帧、截断和空流，捕获数据错误；不验证内部缓存实现。
2. HTTP 流接口：相同种子数据一致、非法规模返回错误、取消停止响应；不模拟真实生产网络。
3. 浏览器控制台：真实 Worker 与 WebGL 下的增量可见、暂停/继续/取消、重载释放、报告导出；离线通过不代表百度地图接入通过。
4. 同数据对照：相同输入、视角、分辨率与交互脚本，多次运行，保留所有原始值。

构建与自动测试在远程工作目录执行；本地编辑与 Git 管理。远程无硬件 GPU 时明确标注软件 WebGL，不能据此宣称目标 GPU 性能。
