# 赛题要求与验收映射

本文根据用户于 2026-10-12 提供的赛题说明整理，用于项目开发与验收追踪。赛事名称、提交时间、数据约束及其他正式规则待核实主办方原文。

## 问题定义

工业园区、能源设施与物流网络需要持续展示大量设备、车辆、人员、管线和业务分区。数据规模增长后，全量下载、集中解析和集中渲染可能增加等待时间、阻塞主线程，并影响地图交互。

本项目需要验证：把获取、解析和渲染组织为可控的增量流水线，并配合 GPU 批量绘制，能否在相同数据和硬件条件下改善首屏与加载期间的交互表现。

## 评分与优先级

| 维度 | 权重 | 开发关注点 |
| --- | --- | --- |
| WebGL 高性能渲染 | 40% | 数据组织、GPU Buffer、批量绘制、Shader、稳定帧率 |
| 流式数据处理 | 25% | 获取到显示的增量链路、首屏、吞吐、可控队列 |
| 实时交互与系统性能 | 20% | 加载与更新期间的缩放、平移、旋转表现 |
| 工业场景与工程实现 | 15% | 场景可信度、完整 Demo、技术说明与测试结果 |

## 性能报告覆盖范围

- 首屏数据展示时间。
- 数据持续加载速度。
- 数据增量渲染效率。
- 最大支持渲染规模及达到限制的条件。
- 地图交互过程中的 FPS。
- 数据加载过程中的 FPS。
- CPU 使用率。
- GPU 使用率。
- 内存占用。

浏览器无法直接提供或当前环境无法可靠采集的指标，应注明采集限制。不能将缺失数据填写为零，也不能将帧时间当成 GPU 使用率。

测量定义与对照约束见 [性能测试计划](performance.md)。
