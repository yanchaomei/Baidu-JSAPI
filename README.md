# Baidu-JSAPI

基于百度地图 JSAPI WebGLLayer，探索工业场景下海量点、线、面数据的流式加载、异步处理与高性能渲染。

> 项目状态：仓库初始化与方案规划阶段。当前尚无可运行 Demo 或性能实测结果。

## 赛题与目标

本项目面向「AI+ 工业软件赛道」百度地图赛题：**基于百度地图 JSAPI 的海量空间数据流式高性能渲染技术**。

核心目标是让空间数据「边下载、边处理、边显示」，在后台持续处理海量数据时，仍能流畅缩放、平移和旋转地图。

首个 Demo 暂定为**工业园区设备与管网运行监控**：设备和车辆用点表示，管网和运输路径用线表示，园区及能源分区用面表示。首阶段使用可复现的合成数据，明确标注数据来源与用途。

## 计划实现的能力

以下能力均为开发目标，完成情况见 [路线图](docs/roadmap.md)。

- **流式处理**：分块获取、增量解析、异步调度、缓存与背压控制。
- **异步解析**：使用 Web Worker 处理解析和几何准备，减少主线程阻塞。
- **GPU 渲染**：通过 WebGLLayer 接入地图，探索分块 Buffer、批量绘制、实例化与 Shader 优化。
- **实时更新**：增量提交设备状态和位置变化，控制更新开销。
- **交互保障**：限制每帧数据提交工作量，并验证加载期间的地图交互表现。
- **可复现测量**：记录首屏、吞吐、帧时间、长任务、内存和 GPU 资源情况。

具体 API、坐标变换及渲染生命周期以百度地图官方接口验证结果为准。

```bash
cd Baidu-JSAPI
```
